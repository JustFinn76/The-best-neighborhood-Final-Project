# The-best-neighborhood-Final-Project

Team Name: Team Flippincoins

Team Members: Finn Snyder (fis14@pitt.edu), Haofeng Li (hal464@pitt.edu)

This project uses real-world data on air quality, bus stops, and crime to determine the best neighborhood in Pittsburgh.

We use the following datasets from the WDRPC for analysis and ranking:

1. Allegheny County Air Quality: https://data.wprdc.org/dataset/allegheny-county-air-quality
2. Pittsburgh Regional Transit Stops: https://data.wprdc.org/dataset/prt-of-allegheny-county-transit-stops
3. Pittsburgh Police Arrest Data: https://data.wprdc.org/dataset/arrest-data
4. Non-Traffic Citations: https://data.wprdc.org/dataset/non-traffic-citations
